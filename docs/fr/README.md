# Parcours francais : account-policies (autorisations restreintes pour smart accounts Base)

Lecture commentee du depot base/account-policies : un mecanisme onchain, wallet-agnostique, pour installer des modules de policy a capacite restreinte sur un compte et executer des actions preparees par ces policies via le compte.

Sommaire :

Chapitre 1 Presentation de account-policies. Chapitre 2 PolicyBinding, policyId et les payloads du cycle de vie. Chapitre 3 Le cycle de vie complet, install, execute, uninstall, replace. Chapitre 4 L interface Policy et la repartition des responsabilites. Chapitre 5 Le pattern SingleExecutorPolicy et ses variantes. Chapitre 6 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
